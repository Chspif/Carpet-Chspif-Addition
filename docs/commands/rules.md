## 所有规则

### 猪灵忽视金纹饰盔甲(piglinIgnoreGoldTrim)

猪灵会像忽视穿戴金盔甲的玩家一样忽视穿戴含有金纹饰盔甲的玩家

- 类型：`布尔值`
- 默认值：`false`
- 参考选项：`true`，`false`
- 分类：`Chspif`，`特性`

### 快捷假人邮寄(commandSend)

使用 `/send` 命令打开快捷邮寄界面,提供一种类似假人邮寄的更方便的方案。

- 类型：`字符串`
- 默认值：`false`
- 参考选项：`0`，`1`，`2`，`3`，`4`，`ops`，`true`，`false`
- 分类：`Chspif`，`命令`

### 检修模式(commandSmallFix)

使用 `/smallfix` 命令切换正常/缩小体型。

- 类型：`字符串`
- 默认值：`false`
- 参考选项：`0`，`1`，`2`，`3`，`4`，`ops`，`true`，`false`
- 分类：`Chspif`，`命令`

### 掉落物发光(glowingItems)

- 类型：`布尔值`

- 分类：`Chspif`，`特性`

### 朱砂可以辟邪(undeadAvoidCinnabar)

部分亡灵生物会被朱砂类驱赶。(详见BV1L48A67EyF)

- 类型：`布尔值`
- 默认值：`false`

- 分类：`Chspif`，`特性`

### 显示区块加载等级和计算等级(commandChunkLoadInfo)

使用 `/chunkloadinfo` 命令查看指定区块的加载等级和计算等级。

- 类型：`字符串`
- 默认值：`false`
- 参考选项：`0`，`1`，`2`，`3`，`4`，`ops`，`true`，`false`
- 分类：`Chspif`，`命令`

### 显示区块MSPT信息(commandChunkMsptInfo)

使用 `/chunkmsptinfo` 等相关命令查看指定区块MSPT占用信息。

    /chunkmsptinfo on/off 开启/关闭实时区块MSPT显示功能
    /chunkmsptinfo status 显示MSPT占用前十的区块
    /chunkmsptinfo calculate chunkpos1 chunkpos2 计算指定范围内的区块MSPT总占用
    /chunkmsptinfo clear 清除可能残留的MSPT信息

- 类型：`字符串`
- 默认值：`false`
- 参考选项：`0`，`1`，`2`，`3`，`4`，`ops`，`true`，`false`
- 分类：`Chspif`，`命令`
