## 所有规则

### 猪灵忽视金纹饰盔甲(piglinIgnoreGoldTrim)

猪灵会像忽视穿戴金盔甲的玩家一样忽视穿戴含有金纹饰盔甲的玩家

- 类型：`布尔值`
- 默认值：`false`
- 参考选项：`true`，`false`
- 分类：`Chspif`，`特性`

### 快捷假人邮寄(commandSend)

使用 `/send` 命令打开快捷邮寄界面,提供一种类似假人邮寄的更方便的方案。

- 类型：`字符串`
- 默认值：`false`
- 参考选项：`0`，`1`，`2`，`3`，`4`，`ops`，`true`，`false`
- 分类：`Chspif`，`命令`

### 检修模式(commandSmallFix)

使用 `/smallfix` 命令切换正常/缩小体型。

- 类型：`字符串`
- 默认值：`false`
- 参考选项：`0`，`1`，`2`，`3`，`4`，`ops`，`true`，`false`
- 分类：`Chspif`，`命令`

### 掉落物发光(glowingItems)

使掉落物发光。

- 类型：`布尔值`
- 默认值：`false`
- 参考选项：`true`，`false`
- 分类：`Chspif`，`特性`

### 矿车发光(glowingMinecarts)

使矿车类发光。

- 类型：`布尔值`
- 默认值：`false`
- 参考选项：`true`，`false`
- 分类：`Chspif`，`特性`

### 玻璃挖掘加速(netheriteHoeGlassSpeed)

下界合金锄可以加速挖掘玻璃类方块，包含玻璃、玻璃板、发光透明方块、蛙鸣灯。

- 类型：`布尔值`
- 默认值：`false`
- 参考选项：`true`，`false`
- 分类：`Chspif`，`特性`
